# ADR-005: Saf çekirdek / dış kabuk mimarisi

- **Durum:** Kabul edildi (2026-10-17)
- **İlgili:** CLAUDE.md (ilk kural), TICK.md, MODEL.md INV-07

## Bağlam
Aynı oyun hem insanlar (pygame-ce) hem RL ajanları (Gymnasium / PettingZoo) tarafından oynanacak. Replay ve
bit düzeyinde test edilebilirlik gerekiyor.

## Karar
`step(state, actions, rngs) -> (new_state, new_rngs, events)` saf ve deterministiktir (RNG durumu değerdir, ADR-011). `engine/` paketi `render/`,
`controllers/`, `envs/`, `logs/`, `tools/` paketlerinin hiçbirini import etmez; yalnızca standart kütüphane,
numpy, pydantic ve pyyaml'ı (config okuma, ADR-008) kullanır. Standart kütüphaneden `random`, `time` ve
`datetime` motorda yasaktır (ADR-006 RNG akışları; motorda duvar saati yok). Durum değişmez nesnelerdir.
Bağımlılık yönü: dış → iç.

```
controllers ─┐
render ──────┤
envs ────────┼──► engine
logs ────────┤
tools ───────┘
```

*Güncelleme 2026-10-18:* `tools/` yasak katmanlara, pyyaml izin listesine eklendi (CLAUDE.md ile uyum;
`engine/config.py` YAML okur); `random`/`time`/`datetime` yasağı açıkça yazıldı.

*Güncelleme 2026-10-25 (ADR-012):* `render/` de bir statik testle korunur
(`tests/render/test_render_imports.py`): `render/` yalnız standart kütüphane, numpy, pygame, `engine` ve kendisini
import eder; `controllers/`, `envs/`, `logs/`, `tools/` yasaktır (araçlar render'ı kullanır, tersi değil).
`render/interpolation.py`, `render/characters/pose.py` ve `animator.py` pygame de import etmez: saftır, pencere
açmadan test edilir.

*Güncelleme 2026-10-25 (Faz 1.1):* `controllers/` da statik testle korunur
(`tests/controllers/test_controllers_imports.py`): yalnız standart kütüphane, numpy, `engine` ve kendisini import
eder; pygame, `time` ve `datetime` yasaktır. Klavye denetleyicisi olayları scancode olarak alır, saat
kullanmaz (tick sınırını oturum bildirir); böylece pencere açmadan ve gerçek zaman beklemeden test edilir
(CONTROLS §4.1).

*Güncelleme 2026-10-25 (Faz 1.3):* En dış katman `game/`: oyun döngüsü. `game/` motoru, `controllers/`'ı ve
`render/`'ı kullanır; **hiçbir paket `game/`'i import etmez** (yalnız `main.py`). `game/session.py` saftır:
pygame, `time` ve `datetime` import etmez. Test: `tests/game/test_game_imports.py`.

```
main.py ──► game ──► controllers, render ──► engine
```

## Sonuçlar
- (+) İnsan oyunu, botlar ve RL eğitimi aynı kodu paylaşır.
- (+) Replay = seed + eylemler; testler pencere açmadan koşar.
- (−) Durum kopyalama maliyeti. Darboğaz ölçülürse yerinde güncellemeye geçilir (arayüz değişmez).
- Sınır statik bir testle korunur (INV-07): `engine/` içindeki her import bir izin listesine karşı denetlenir
  (`tests/invariants/test_INV07_engine_imports.py`). Dinamik import (`importlib`) statik testin kapsamı dışıdır.

## Değerlendirilen alternatifler
- **Oyun döngüsüne gömülü mantık (klasik pygame):** RL ve replay için yeniden yazım gerektirir.
- **ECS çatısı:** bu ölçekte gereksiz karmaşıklık.
